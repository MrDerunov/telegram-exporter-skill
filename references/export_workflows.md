# Типовые сценарии экспорта

Все сценарии выполняются через графический интерфейс приложения.

## Базовый экспорт

1. Запустить приложение, войти в аккаунт
2. В списке чатов найти нужный чат (поиск по названию, фильтр по папкам)
3. Выбрать чат → откроется окно настроек экспорта
4. Выбрать формат: **JSON**, **Markdown**, или **оба**
5. Нажать «Экспорт»

Результат сохранится в выбранную директорию (по умолчанию — рядом с приложением).

## Фильтры

### Период
- **Последняя неделя** / **Последний месяц** — быстрые пресеты
- **Свой диапазон** — выбор дат через календарь (date picker)

### Папки Telegram
- В списке чатов можно отфильтровать по папкам Telegram («Работа», «Личное» и др.)
- Выбрать папку → видны только чаты из этой папки

### Авторы
- Можно выбрать экспорт сообщений только от конкретных авторов

## Медиа

### Скачать все медиа
- В настройках экспорта включить **«Скачивать медиа»**
- Фото, видео, голосовые, документы сохранятся в папки `media/`

### Транскрипция голосовых
- Включить **«Транскрибировать голосовые»**
- Выбрать провайдера:
  - **Локально (Whisper)** — офлайн, требует CPU/GPU
  - **Deepgram** — облачно, нужен API-ключ (вводится в настройках)

Ограничение: одно голосовое/кружок не длиннее 15 минут.

## Аналитика

- В настройках экспорта включить **«Аналитика»**
- Создаёт:
  - `top_authors.md` — топ авторов по количеству сообщений
  - `activity.md` — активность по датам

## Инкрементальный экспорт

- При повторном экспорте того же чата приложение автоматически дозабирает только новые сообщения
- История последнего экспорта хранится в `~/.tg_exporter/export_history.json`

## Массовый экспорт

- В списке чатов можно выбрать несколько чатов
- Настроить общие параметры экспорта
- Запустить экспорт для всех выбранных чатов

## Структура вывода

```
<output>/
├── result.json              # Полный JSON со всеми сообщениями
├── _part_1.md               # Markdown, часть 1
├── _part_2.md               # Markdown, часть 2 (если >лимита слов)
├── media/
│   ├── photos/              # Фото (.jpg, .png)
│   ├── videos/              # Видео и кружки (.mp4)
│   ├── voices/              # Голосовые (.ogg)
│   ├── documents/           # Документы
│   └── stickers/            # Стикеры (.webp)
├── top_authors.md           # Аналитика: топ авторов
├── activity.md              # Аналитика: активность по датам
└── export_history.json      # Метаданные последнего экспорта (для инкрементального)
```
