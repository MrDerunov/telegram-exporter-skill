# Гайд по авторизации в Telegram Exporter

## Получение API ключей

1. Перейти на https://my.telegram.org
2. Войти под своим номером телефона
3. Выбрать «API development tools»
4. Создать приложение (если ещё нет)
5. Сохранить **api_id** (число) и **api_hash** (строка)

## Первый вход

1. Запустить приложение
2. В окне логина ввести:
   - **API ID** — число из my.telegram.org
   - **API Hash** — строка из my.telegram.org
3. Нажать «Далее»
4. Ввести **номер телефона** в формате +79991234567
5. Ввести **код из Telegram** (придёт в приложение/смс)
6. Если включена двухфакторная аутентификация — ввести **пароль 2FA**

## Несколько аккаунтов

1. Войти под первым аккаунтом
2. В шапке приложения нажать **«Аккаунт ▾»** → **«Добавить аккаунт»**
3. Повторить шаги первого входа для нового аккаунта
4. Переключаться между аккаунтами через выпадающее меню **«Аккаунт ▾»**

## Выход из аккаунта

1. Нажать **«Аккаунт ▾»** в шапке
2. Выбрать аккаунт → **«Выйти»**

Сессия будет удалена из Keyring.

## Диагностика проблем

### «Ошибка соединения, проверьте интернет»
- Включи VPN с полным туннелированием трафика (AmneziaVPN, Outline, WireGuard)
- Обычные «VPN для сайтов» (браузерные расширения) не работают — приложение ходит напрямую к серверам Telegram
- Попробуй другой VPN, если первый не сработал

### Не приходит код
- Проверь что номер введён в правильном формате (+7999...)
- Проверь Telegram на других устройствах — возможно код пришёл туда
- Запроси код повторно через некоторое время

### «Неверный API ID/Hash»
- Проверь что скопировал без лишних пробелов
- api_id — это число (например 123456)
- api_hash — это строка (например a1b2c3d4e5f6...)
- Создай новое приложение на my.telegram.org если старые ключи не работают
